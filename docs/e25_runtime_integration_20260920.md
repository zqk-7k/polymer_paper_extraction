| 位置 | 接入内容 |
|---|---|
| Stage 0 | 保守恢复被 OCR 误分到参考文献的实验表征段落 |
| Stage 2–3 | 聚合物/样品标签、组成和状态处理；Stage 3 提示词 1.7.0 |
| Stage 4 | 提示词 1.8.1、局部格式隔离、证据保留、`source_refinement` 1.7.0 |
| Stage 4 内部细化 | 科学计数法、明确区间、倍率、单位、热峰、失重关系、来源样品原始标签 |
| Preview Stage 4R / 4P | 表格合并和有证据、可归属记录的确定性发布恢复 |
| Stage 5–6 与候选发布 | 输出保留、引用和系列点上下文兼容 |

大流程仍为 0–6。4R/4P 属于性质阶段后的 Preview 内部操作，4P 不调用模型；
它失败时留下诊断，不取消其他论文。Stage 4 细化失败保留原基础输出并写出审计文件。
不确定样品关系保持 unresolved，不通过猜测 sample_id 提高显示数量。

这不是“只替换前端”：共用的解析、Schema、Stage 4 细化和提示词也会影响 Strict。
Strict 仍执行既有校验，不启用 Preview 的 4P 和放宽行为；不宣称 Strict 内容逐字不变。
