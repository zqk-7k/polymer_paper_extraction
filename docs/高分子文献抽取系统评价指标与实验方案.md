# 高分子文献抽取系统评价指标与实验方案

## 1. 评价目标

本项目不能只回答“抽出了多少条数据”，而应回答以下五个问题：

1. 论文中的聚合物、样品、工艺、性质和条件是否被完整识别？
2. 性质是否绑定到正确的样品，工艺是否连接到正确的前后状态？
3. 数值、单位和规范名称是否正确？
4. 每条事实是否能够定位到支持它的原文页码、文本或表格单元格？
5. 系统给出的置信度能否可靠地区分“可自动发布”和“需要人工复核”的记录？

因此，评价应从“实体识别 F1”扩展到“样品级完整记录、关系图、证据和发布可靠性”。

## 3. 基本指标及适用范围

对任一评价对象，先定义：

- `TP`：系统输出且与 gold truth 匹配；
- `FP`：系统输出但 gold 中不存在、绑定错误或无原文支持；
- `FN`：gold 中存在但系统没有输出。

计算：

\[
Precision = \frac{TP}{TP+FP}
\]

\[
Recall = \frac{TP}{TP+FN}
\]

\[
F1 = \frac{2 \times Precision \times Recall}{Precision+Recall}
\]

### 3.1 Accuracy 不能作为抽取主指标

`Accuracy=(TP+TN)/(TP+TN+FP+FN)` 适用于“论文是否相关”“记录是否可发布”等封闭分类任务。实体和关系抽取中的负例数量巨大且定义不稳定，即使什么都不抽，Accuracy 也可能很高。因此：

- 抽取任务以 Precision、Recall、F1 为主；
- 分类任务可使用 Accuracy，并同时报告 macro F1；
- 类别不平衡时，不能只报 Accuracy。

### 3.2 Micro 与 macro

- `micro F1`：汇总所有对象的 TP、FP、FN 后计算，作为主指标；
- `macro F1`：先对每类分别计算 F1，再取平均，用于防止高频类别掩盖低频类别；
- 同时列出每个实体、关系和性质类别的分数。

## 4. 本项目的分层指标

## 4.1 PDF 解析与版面恢复

| 指标 | 判定方法 | 用途 |
|---|---|---|
| 文档解析成功率 | 成功生成可用正文、表格和页面图像的论文数 / 总论文数 | 工程稳定性 |
| 文本字符错误率 CER | OCR 字符编辑距离 / gold 字符数 | 扫描 PDF 质量 |
| 表格单元格 F1 | 行、列和单元格内容同时匹配 | 表格恢复能力 |
| 图表召回率 | gold 中含目标数据的图表被识别的比例 | 检查图中数据漏失 |
| 页码保持准确率 | 解析块页码与 PDF 页码一致的比例 | 证据定位基础 |

原生文本 PDF 与扫描 PDF 应分组报告，避免 OCR 难度掩盖后续抽取能力。

## 4.2 实体识别

实体类型至少包括：

- PolymerEntity；
- Sample；
- ProcessStep；
- Property；
- Value；
- Unit；
- MeasurementCondition；
- CharacterizationMethod。

报告两种匹配口径：

1. **严格匹配**：原文 span 边界和实体类型全部一致，作为论文主结果；
2. **宽松匹配**：规范化后文本一致，或 token 重叠超过预注册阈值，仅用于错误诊断。

每类报告 Precision、Recall、F1，并报告 micro F1 和 macro F1。

## 4.3 聚合物统一实体与名称归一

| 指标 | 定义 |
|---|---|
| 规范名称准确率 | mention 被映射到正确 canonical polymer 的比例 |
| 聚合物类型 macro F1 | 均聚物、共聚物、共混物、复合材料等分类的 macro F1 |
| 别名聚类 B-cubed F1 | 对简称、全名、商品名和化学名的聚类质量进行评价 |
| 未解析率 | 无法可靠归一的 mention 数 / 全部 polymer mention 数 |

不能用字符串完全一致评价聚合物名称。例如 `poly(ethylene oxide)`、`PEO` 和规范中文名可能属于同一实体。

## 4.4 样品识别与层级绑定

这是本项目相对现有高分子抽取工作的重点。

| 指标 | 定义 |
|---|---|
| 样品检测 P/R/F1 | gold Sample 与预测 Sample 匹配后的对象级指标 |
| 样品数量完全正确率 | 预测样品数与 gold 完全一致的论文比例 |
| Polymer-Sample edge F1 | 样品是否挂到正确 PolymerEntity |
| 性质-样品绑定准确率 | 已正确抽取的性质中，绑定到正确样品的比例 |
| 样品错绑率 | 挂到错误样品的性质数 / 有原文支持的预测性质数 |
| 状态区分召回率 | 退火、淬火、干燥、湿态等 gold SampleState 被区分的比例 |

样品对象名称可能不同，匹配时应使用匈牙利算法，根据样品标签、所属聚合物、组成、状态和关联证据计算对象相似度，然后评价边关系。

## 4.5 工艺流程图

| 指标 | 定义 |
|---|---|
| 工艺步骤 P/R/F1 | 工艺类型及关键参数匹配 |
| 输入输出边 F1 | `input_sample -> ProcessStep -> output_sample` 是否正确 |
| 工艺参数 F1 | 温度、时间、溶剂、气氛、压力等字段是否完整正确 |
| 顺序准确率 | 被正确排序的工艺步骤对 / 可比较步骤对 |
| 完整工艺链准确率 | 整篇论文的步骤、顺序和输入输出边全部正确的比例 |
| 归一化编辑距离 | 预测工艺序列变成 gold 序列所需编辑次数 / 较长序列长度 |

节点 F1 高但输入输出边 F1 低，说明系统“识别了工艺词，却没有恢复实验流程”。这两类结果必须分开报告。

## 4.6 性质观测与测量条件

建议定义两个端到端记录口径：

### 核心性质记录

```text
(paper, polymer, sample, property_name, normalized_value, normalized_unit)
```

### 完整上下文记录

```text
(paper, polymer, sample, property_name, normalized_value, normalized_unit,
 method, measurement_condition, evidence)
```

对两种记录分别计算 Precision、Recall 和 F1。完整上下文记录 F1 应作为系统的核心论文指标之一。

数值匹配规则：

1. 先进行单位换算；
2. 对离散值按预注册的绝对或相对容差匹配；
3. 区间、上限、下限和误差范围不能压成单值比较；
4. 图中读取值应按图的分辨率或原文有效位数设置容差；
5. 每类性质的容差必须在测试前冻结。

辅助指标：

| 指标 | 定义 |
|---|---|
| 数值准确率 | 匹配记录中数值在容差内的比例 |
| 单位识别准确率 | 原始单位是否正确识别 |
| 单位规范化准确率 | 换算后的数值和标准单位是否同时正确 |
| 方法绑定准确率 | DSC、DMA、GPC 等是否绑定到正确观测 |
| 条件字段 micro F1 | 温度、升温速率、频率、湿度等字段级 F1 |
| 条件完整率 | gold 必要条件中被抽取的比例 |

## 4.7 原文证据与 bbox

仅有 `evidence_id` 不代表证据正确。建议分四层评价：

| 指标 | 定义 |
|---|---|
| 原文支持 Precision | 预测事实中，证据确实支持该事实的比例 |
| 证据 Recall | gold 事实中，系统提供了有效证据的比例 |
| 页码准确率 | evidence page 与 gold page 一致的比例 |
| bbox IoU | 预测框与 gold 框交并比 |
| gold 覆盖率 IoG | 预测框与 gold 框交集面积 / gold 框面积 |
| 文本证据 token F1 | 预测证据文本与 gold 证据文本的 token 级 F1 |
| 无支持生成率 | 无有效原文支持的预测事实 / 全部预测事实 |

红框定位建议同时使用：

- `page accuracy`；
- `IoG >= 0.8` 判断是否覆盖完整 gold 证据；
- `IoU` 衡量红框是否过宽；
- 专家判断证据是否足以支持该事实。

表格证据还应单独报告 `table_id + row + column + cell` 的定位准确率。

## 4.8 图结构总体质量

| 指标 | 定义 |
|---|---|
| 节点 micro F1 | 所有 Polymer、Sample、Process、Measurement 节点汇总 |
| 边 micro F1 | 所有归属、输入输出、测量和证据边汇总 |
| 路径准确率 | `Polymer -> Sample -> Property -> Evidence` 完整路径正确的比例 |
| 归一化图编辑距离 | 将预测图修改为 gold 图所需操作数 / gold 图规模 |
| 引用完整率 | 所有对象 ID 引用均存在且类型合法的比例 |

图编辑距离适合总体诊断，但解释性较弱；论文主结果仍应以节点、边和完整路径指标为主。

## 4.9 置信度与选择性发布

置信度不能直接采用 LLM 自报分数。应在 calibration set 上，根据模型一致性、证据定位、Schema 校验、单位规则和跨阶段一致性训练或拟合正确概率。

| 指标 | 用途 |
|---|---|
| Brier score | 预测置信度与实际正确性的均方差，越低越好 |
| ECE | 置信度分桶后，置信度与真实准确率的差异 |
| AUPRC | 区分正确与错误记录，适合类别不平衡 |
| 自动发布 Precision | 超过阈值并自动发布的记录中，完全正确的比例 |
| 自动发布覆盖率 | 自动发布记录数 / 全部候选记录数 |
| risk-coverage 曲线 | 随置信度阈值改变，错误风险与覆盖率的关系 |

数据库质量更重视高 Precision。建议把“在自动发布 Precision 不低于 99% 时能覆盖多少记录”作为核心工程指标，而不是追求最高平均置信度。

## 4.10 工程效率与人工成本

每个系统或消融组同时报告：

- 成功完成论文比例；
- 每篇平均耗时和 P50/P95 耗时；
- 每篇 token 数与 API 费用；
- 平均模型调用次数和重试次数；
- 每篇人工审核时间；
- 每 100 条记录人工修改数；
- 单位时间内可发布的正确记录数。

## 5. Gold benchmark 建设

### 5.1 数据划分

最低可执行版本：

| 集合 | 建议论文数 | 用途 |
|---|---:|---|
| development | 20 | 修改 prompt、规则和 schema |
| calibration | 10 | 校准置信度和发布阈值 |
| frozen gold test | 20 | 最终报告，禁止调参 |
| stress set | 10 | 共混物、共聚物、长表格、跨页关系和图片性质 |

面向高水平论文，建议将冻结测试集扩充至 40 篇以上，并覆盖：

- 均聚物、共聚物、共混物和复合材料；
- 正文、表格、图和补充信息；
- 热学、力学、电学、分子量和形貌性质；
- 单样品论文与多样品梯度论文；
- 原生文本 PDF 与扫描 PDF。

### 5.2 标注与一致性

1. 两名标注者独立标注冻结测试集；
2. 高分子专家裁决分歧；
3. 实体报告严格 span F1；
4. 分类字段报告 Cohen's kappa；
5. 关系报告完整关系 F1；
6. 样品边界、状态和性质挂靠必须单独记录分歧；
7. 裁决后的版本才作为最终 gold。

所有指标按 DOI 做 bootstrap，报告 95% 置信区间，不能把同一论文中的大量记录当作完全独立样本。

## 6. 公平对照与消融实验

### 6.1 基线组

| 组别 | 系统 |
|---|---|
| B0 | 单次 LLM：整篇文本直接输出目标 JSON |
| B1 | 分阶段 workflow，但不执行样品优先关系恢复 |
| B2 | workflow + 样品和工艺关系恢复 |
| B3 | workflow + 样品关系 + Schema/单位规则 |
| Full | 当前完整系统 + 表格恢复 + evidence matcher + Stage 6 发布校验 |

所有组使用同一 PDF、同一解析结果、同一模型版本和同一 gold，避免把 PDF 解析差异或模型差异误认为架构收益。

### 6.2 关键消融

| 消融 | 要证明的问题 | 重点观察指标 |
|---|---|---|
| 去掉 Stage 3 样品优先抽取 | 样品层是否必要 | 性质-样品绑定准确率、错绑率、完整记录 F1 |
| 去掉 Stage 4R 表格恢复 | 表格补召回是否有效 | 表格性质 Recall、总体 Recall、FP 增量 |
| 去掉 evidence matcher | 确定性证据匹配是否有效 | 证据 Recall、无支持生成率、bbox 定位率 |
| 去掉单位与物理规则 | Harness 是否提高可信度 | 单位准确率、数值错误率、发布 Precision |
| 去掉 Stage 6 隔离发布 | 坏对象是否会污染整篇结果 | 可发布覆盖率、论文成功率、错误对象残留率 |
| 去掉实体归并 | 名称统一是否必要 | canonical accuracy、重复实体率、样品归属 F1 |

## 7. 建议的论文主指标

论文摘要和主表不宜放十几个同等重要的指标。建议预注册四个主指标：

1. **完整上下文记录 micro F1**：整体抽取质量；
2. **性质-样品绑定准确率**：是否解决高分子样品错挂问题；
3. **原文支持 Precision**：每条事实是否真的有证据；
4. **99% 自动发布 Precision 下的覆盖率**：能否形成生产级数据库。

辅助指标包括：实体/关系分类别 F1、工艺边 F1、单位准确率、bbox 定位率、耗时、费用和人工审核时间。

## 8. 建议验收目标

以下为工程目标，不是当前已取得的结果，需在 pilot 后冻结：

| 指标 | 建议目标 |
|---|---:|
| PolymerEntity 严格 F1 | >= 0.90 |
| Sample 对象 F1 | >= 0.85 |
| 核心性质记录 micro F1 | >= 0.90 |
| 完整上下文记录 micro F1 | >= 0.80 |
| 性质-样品绑定准确率 | >= 0.95 |
| 样品错绑率 | <= 0.02 |
| 单位规范化准确率 | >= 0.98 |
| 原文支持 Precision | >= 0.98 |
| evidence 页码准确率 | >= 0.98 |
| 无支持生成率 | <= 0.01 |
| 自动发布 Precision | >= 0.99 |

如果完整上下文 Recall 暂时较低，应允许系统进入人工复核，不能通过删除难例来虚增 Precision。

## 10. 当前项目最需要补的实现

当前自动化测试主要验证代码行为和 Schema 约束，还不是面对人工 gold 的科学评价。下一阶段应新增独立 `evaluation/` 模块：

```text
evaluation/
  gold/                    # 冻结人工标注
  matching/                # entity/sample/observation/graph 匹配
  metrics.py               # P/R/F1、校准、bbox 和效率指标
  evaluate_run.py          # 对单次流水线结果评分
  bootstrap.py             # DOI 级置信区间
  error_taxonomy.py        # 错误归因
  reports/                 # CSV、JSON、图表输入
```

第一版优先实现：

1. PolymerEntity、Sample 和 PropertyObservation 对象匹配；
2. `Polymer -> Sample -> Property -> Evidence` 完整路径 F1；
3. 性质-样品绑定准确率和样品错绑率；
4. evidence 页码、bbox、原文支持评价；
5. DOI bootstrap 95% CI；
6. baseline/ablation 统一结果表。

只有完成这套 gold-based evaluation，当前系统才能从“可运行的抽取工具”升级为“可在论文中被独立验证的抽取方法”。
