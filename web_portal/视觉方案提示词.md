# PolymerLit Extractor 备选视觉方案提示词

## 使用说明

以下提示词用于让其他 AI 在现有项目上实现新的视觉分支。必须要求 AI 直接修改 React、TypeScript 和 CSS，运行真实页面并截图验收，不接受只输出设计说明、Figma 概念图或静态 HTML。

项目位置：`D:\polymer\paper_capture\polymer_paper_extraction\web_portal`

必须保留的功能：

- 上传 PDF，展示 Stage 0–5 的真实运行状态。
- 网页历史抽取结果和离线批处理结果相互独立。
- 论文 → 聚合物 → 样品 → 性质的逐层跳转。
- 聚合物 PID、CU formula、结构式占位和样品数量。
- 样品性质表、加工过程、测量条件、置信度和原文证据。
- 知识图谱中的论文、聚合物、样品状态、工艺事件、性质和表征关系。
- 根据 PDF 页码和 bbox 显示完整页面红框及局部证据裁剪图。
- 候选结果和未完成科学校验的警告必须保持醒目。

通用约束：

- 不改变 API、JSON Schema、对象 ID 和页面跳转逻辑。
- 不创建营销首页；首屏仍是可直接使用的文献上传工具。
- 不使用大面积渐变、装饰光球、虚假 3D 分子、廉价霓虹或游戏化 HUD。
- 页面区块不套娃；卡片只用于单个实体、单个工具或重复项目。
- 结构、关系、证据和不确定性必须比装饰更醒目。
- 桌面端 1440、1920 像素以及移动端 390 像素均需截图验收。
- 所有文本必须完整可读，不得水平溢出或与按钮重叠。

## 方案 A：Nature Scientific Atlas

```text
你是一名同时熟悉 Nature 系列科研图形、科学数据库和高端编辑设计的产品设计师与前端工程师。请直接重构 PolymerLit Extractor 的真实 React 页面，设计一套“Scientific Atlas”视觉系统。

目标不是把页面做成普通 SaaS 仪表盘，而是让它像一本可交互的高水平材料科学图谱：严谨、安静、证据优先、适合科研人员长时间阅读。整体采用温和白色与极浅中性灰背景，正文使用近黑色，主强调色为 Nature 风格的深红或蓝绿色，但主色面积不得超过页面的 12%。类别颜色使用色盲友好组合：蓝、蓝绿、橙、紫、绿、灰。禁止大面积蓝色背景和大面积渐变。

版式要求：使用 12 列响应式网格，桌面端内容接近全宽，但每个信息块有清晰对齐线。标题更像论文图题而不是营销标题。论文摘要区域使用一条细色标表示数据来源，作者、DOI、年份形成规范元数据行。统计指标采用紧凑的横向数据带，不要五张漂浮大卡片。表格使用明确的列层级、充足行高、细分隔线和数值对齐。

聚合物目录要像材料数据库条目：左侧是结构或结构占位，中部是规范名称、PID、CU formula、别名和类型，右侧是样品数量、置信度与进入按钮。不要在大卡片内留下没有意义的空白。聚合物详情和样品详情必须使用独立全页布局，并保留返回上一级。

知识图谱是页面重点。将图谱设计成投稿级机制图的交互版本：白色画布、非常浅的点阵辅助线、六个水平阶段标题、白色节点、类别色左边线、清楚的箭头和关系标签。节点位置必须由真实父子关系决定。节点选中后突出其一跳邻居，其他节点降低透明度。严禁随机散点和蜘蛛网布局。增加图例、节点数、关系数、关系主干/全部实体切换，但避免工具栏拥挤。

证据抽屉要像科研证据阅读器：左侧显示 PDF 整页及红色 bbox，右侧显示同比例高清裁剪，下面展示原文、页码、对象 ID、抽取阶段与来源类型。红框必须精确，裁剪图不得变形。候选数据警告使用克制但明确的琥珀色。

使用现有 Ant Design、Lucide 和 React Flow，不增加无必要依赖。实现后运行 lint、build、test，并输出上传页、聚合物目录、知识图谱、样品性质页和证据抽屉的桌面截图，以及一张 390px 移动端截图。根据截图修复所有溢出、稀疏和视觉层级问题后再交付。
```

## 方案 B：Apple Laboratory OS

```text
请把 PolymerLit Extractor 重构成一套 Apple Laboratory OS 风格的科研工具。请直接编辑现有 React、TypeScript 和 CSS，不要只生成概念图。

设计关键词：精密、轻盈、安静、触感明确、材质克制、信息密度高。参考 macOS 系统设置、Apple Developer 工具和高端实验仪器软件，而不是 Apple 官网营销页。背景为冷中性浅灰，内容面板为接近白色，导航可使用石墨黑。只在顶部栏、抽屉和浮动控制器上使用轻度透明与背景模糊。禁止玻璃卡片泛滥，禁止彩色光球和大面积渐变。

采用系统字体栈 SF Pro、Segoe UI、Microsoft YaHei。中文正文至少 14–15px，主标题 30–34px，表格行高舒适。所有圆角不超过 8px。阴影极轻，仅用于表达层级，不用于装饰。主操作色使用 Apple Blue，成功、警告、错误分别使用独立的绿、琥珀和红，不要把整个页面染成蓝色。

左侧导航采用石墨黑背景，激活项使用低对比深灰底和一条细蓝色状态线。顶部栏固定并轻微磨砂，服务在线状态必须清楚。内容区域在 1920px 下充分利用宽度，左右边界严格对齐。

上传页要像系统任务控制台：上传工具与流水线状态并列，卡片自然高度，不强制等高。Stage 0–5 使用连续时间轴，已完成、运行中、失败和等待状态要一眼可辨。按钮使用图标和简短文字。

抽取结果页采用“论文元数据 → 关键计数 → 数据视图”的稳定层级。聚合物目录条目要紧凑，结构区域和身份区域比例合理。聚合物页与样品页是独立全页，不允许嵌在论文结果卡片中。

知识图谱要像专业系统架构查看器：白底精密画布、规则列布局、关系色可区分但低饱和；节点为白色，左侧 4px 类别色边线，悬停与选中有轻度抬升。禁止默认 React Flow 外观、随机布局和艳丽霓虹。

证据抽屉应像 Preview 与数据检查器的组合：整页预览、红框定位、局部放大和元数据分区明确。必须使用真实 bbox 计算，不得用示意红框。

完成后用真实数据逐页截图验收，包含上传、目录、图谱、性质表和 bbox 证据。修复水平溢出、文本裁切、卡片空白过大和移动端按钮拥挤。运行 lint、test 和 production build。
```

## 方案 C：Advanced Instrument Console

```text
请为 PolymerLit Extractor 实现一套“先进材料实验仪器控制台”视觉方案。直接修改现有前端工程并运行，不要输出静态 mockup。

整体采用双层主题：全局导航和知识图谱控制区域为深石墨色，论文、样品、性质和证据阅读区域保持白色或极浅灰。目标是专业仪器软件，不是赛博朋克。禁止纯黑大面积正文、荧光绿字符、霓虹描边、扫描线、发光粒子和复杂动画。

颜色系统必须可用于科学分类：论文蓝、聚合物紫、样品蓝绿、工艺橙、性质绿、表征灰。颜色仅用于状态线、图标、关系和少量标签。正文始终保持高对比度。使用等宽字体只显示 PID、sample ID、对象 ID、DOI 和数值；普通文本使用现代无衬线字体。

页面采用宽屏工作站布局。左侧导航窄而稳定，顶部显示服务状态、当前任务和导出命令。上传页显示真实任务阶段和日志工件。结果页强调逐层关系，不要把所有实体平铺在一个列表中。

知识图谱需要成为全屏可用的主工具：提供阶段栏、关系图例、缩放控制、小地图、主干/全部切换。图谱布局固定为论文 → 聚合物 → 样品状态 → 工艺事件 → 性质 → 表征六列；节点纵向位置由亲缘关系决定。点击样品跳转样品页，点击聚合物跳转聚合物页，点击性质或工艺打开对应证据。使用清晰箭头，不让连线穿过文字。

性质表采用仪器数据表风格：数值右对齐，单位独立列，条件、方法、置信度与证据均可见。证据阅读器并排显示整页和裁剪区域，用红框准确标注 bbox，并允许打开原始 PDF。

交互动画只允许 120–180ms 的淡入、边框变化和轻微位移。减少不必要卡片，避免卡片套卡片。所有尺寸需在 1440、1920、390px 下通过真实截图检查。最终运行 lint、test 和 build，并报告修改文件和验收截图。
```

## 方案 D：Swiss Data Laboratory

```text
请把 PolymerLit Extractor 设计为 Swiss International Style 与现代科学数据平台结合的界面。直接在现有 React 工程中实现。

使用严格网格、清晰基线、大量高质量留白、近黑正文、白色内容面和极浅灰分区。主色只使用一种高识别度蓝色，实体类别再使用五种低饱和辅助色。标题左对齐，减少装饰图标，强调文字、编号和数据。不得使用渐变、玻璃拟态、深色大背景、发光效果或超大圆角。

将论文信息视为一个正式数据记录头：题名、作者、期刊、年份、DOI、来源编号按网格排列。统计信息改为一条连续数据带。聚合物目录使用编号列表，每行清楚包含结构、名称、PID、CU formula、类型、样品数和置信度。独立的聚合物页和样品页应像数据库记录详情，而不是营销卡片。

知识图谱设计为科学信息图：列布局、直角或平滑正交连线、简洁图例、明确关系标签。节点使用白底、细边框和一条类别色编码，不使用彩色填充。证据抽屉采用出版物校样风格，PDF 页和 bbox 裁剪是视觉中心。

中文字体不得过小，表格列要对齐，ID 和数值使用 tabular numerals。候选数据警告、空值、待复核和无证据必须有一致语义。完成后用真实数据截图逐页修正并运行全部测试。
```
