# IUPAC 名称与持续改进路径

当前任务 `IDENTITY-IUPAC-READER-20261001-01`。运行内核仍为 0.9.0，旧命名合同和首次封存结果可回放。这里的改进是明确范围的命名规则、证据校验与阅读界面，不等于独立化学审核或认证优选名。

## 本次处理的 21 + 4

| 原分类 | 对象与数量 | 现在可以做到 | 仍需什么 |
|---|---|---|---|
| 不支持 4 | PMPCSK、硅氧烷 2、等规 PP、EPDM | 使用已核图的单体名称、明确来源关联与来源立构，得到来源型名称。EPDM 只用 co，保留未知序列。 | 从来源型转成结构型需实测构成、序列、端基和立构；硅氧烷的图示三联不能直接成为实物周期序列。 |
| 材料描述 1 | 光交联 PMPCSK | net- 来源型网络名称；局部环丁烷图及光交联限定分开显示。 | 连接位点、交联率、立构、网络拓扑。 |
| 材料描述 5 | 高转化率产物、b-PP/b-PP1/b-PP2、低分子量 PP | 给出基础来源名称；加工、不溶状态、分子量等作为身份限定。 | 加工是否改变共价构成，支化/降解/端基及分布。基础名称不唯一标识实物样品。 |
| 材料描述 2 | 对照 PP/EPDM、低分子量 PP/EPDM | 使用 -blend- 连接组分来源名称；组成比和样品状态另列。 | 50/50 的基准、相的身份分布，不能由该比例补出 CRU。 |
| 材料描述 6 | DMI/MMI 功能化 PP 及其成员 | 基础 PP 名称可验证，功能化描述、前体图及有条件局部图可读。 | 孤立残基与聚合接枝链比例、连接原子、侧链长度、MMI 酯位和环酐形态。证实聚合侧链后才可使用 -graft-poly(...)。 |
| 材料描述 6 | 含上述接枝相的共混及成员 | -blend- 关系成立，但其接枝组分仍为限定描述；整体不称完整 IUPAC 名。 | 先解决接枝相；不能用共混连接词掩盖其未知构成。 |
| 材料描述 1 | MMI | 两个系统名称分别经实际 OPSIN 解析并与两个有限图匹配，显示候选集。 | 来源的酯位选择证据；不强选一个。 |

来源型和结构型命名都在 IUPAC 聚合物命名体系中。依据：[IUPAC Brief Guide §3 与表 1/2](https://iupac.org/wp-content/uploads/2019/07/140-Brief-Guide-to-Polymer-Nomenclature-Web-Final-d.pdf)。这里报告的是声明范围的规则支持，不把 OPSIN 可解析、数据库名称或图往返一致升级为 PIN。

## 实际执行流程与合理性

PDF 经 MinerU 解析并保存正文、页图和来源索引 → 一个持续模型主会话理解本篇、直接读结构页 → 用实际工具接收范围化图、计算图式和性质、保存组分/组成/立构/样品状态及未知 → 同一个 Kernel/create_passport/NamingService 构造身份证和命名证据 → 有限名称经 OPSIN 核图，来源型名称经来源单体和关系校验，完整理想重复图才走重复构成命名 → 当前材料与其依赖组分的状态哈希复核 → 原子封存、采用并读回 → 工作台、文献页和组分库读同一版本。

本次没有重新抽取四篇文献、调用新模型或重跑 MinerU。使用四篇当前封存的来源事实和实际回执，在新的修订目录显式改名、记录撤回、形成新不可变 bundle。首跑证据保持原样。该流程的合理之处是把来源事实、有限工具候选、局部图、完整理想重复和实物身份分开；不足是复杂候选仍依赖模型判断和有限规则，未完成独立化学复核。

## 已落地的规则基础

`identity-evidence-nomenclature/1.0` 是显式声明合同：均聚/未知序列共聚、基础材料+状态、net 网络、物理 blend、功能化部分身份、有限异构体候选集。名称/图一致性依然调用既有 Kernel。子组分名称、图或未知改变会使上层复核哈希失效。

`iupac-triazine-graph-candidate/1.0` 从完整图拆出三嗪、phenylimino 和直链亚烷基，采用既有子单元构造器与周期图比较。支持 H/Me/Ph 三嗪取代与适用的 C2–C20 桥；不会查材料编号或答案表。九个原三嗪重复图现在能得到由图生成的候选，旧 1.1 仍返回原来的范围缺口。优选 CRU 自由价/取代基位次证明未完成，结果仍是候选。

## 如何持续提升

1. **来源命名覆盖**：新文献显式保存单体身份、实际图核对、聚合来源关系、来源立构；有歧义时保存候选集。禁止从原料名自动推产物。
2. **结构型规则**：以三嗪候选为起点补优选 CRU 位次与方向规则，随后扩展完整子单元分解、硅氧烷取代和复杂甲基丙烯酸酯侧基。规则版本独立冻结，保留旧重放。
3. **补充构成证据**：接枝/网络/EPDM 先补真正缺失的连接与序列证据；只有适用时再建立全范围图。未报告事实不能靠增加 parser 或 LLM 调用解决。
4. **独立评审与回归**：新增不同桥长、方向、超胞、区域异构体、盐/电荷/同位素/立构的正反例，记录规则拒绝与撤回。独立人员确认后才标独立审核；实现自己的往返校验不算独立确认。人工 JSON 与旧版本只能用于分离的评估，不能进入求解代码。
5. **交付门槛**：分别统计规则生成、名称核图、来源规则支持、部分身份和未解决证据；不汇成一个“正确率”掩盖范围差异。新论文的无人干预首跑仍须单独实测。

当前下一阻塞点是复杂 CRU 优选规则和接枝/网络的构成证据，而不是没有地方显示名称。首选推进三嗪优选位次的独立例证包；接枝与网络保持明确未知，待有新来源再推进。
