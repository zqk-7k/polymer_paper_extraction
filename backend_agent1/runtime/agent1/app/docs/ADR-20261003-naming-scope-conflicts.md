# 新任务命名采用与冲突合同 1.1

任务：IDENTITY-NAMING-SCOPE-CONFLICT-20261003-01。用户授权执行通用优化；未改变原有测试要求或化学内核0.9.0，独立审核NOT_REVIEWED。

问题是宿主采用范围，而不仅是模型能否想到名称。旧结构表达把相对立构前缀视为字符串不一致；来源/接枝入口依赖有限单体；证据不足时容易把一个可行模型标成最可能。大批里还出现原图与解析数值未分别保留。

新任务显式使用iupac-model-assisted/1.1及identity-model-nomenclature/1.1。旧1.0回放与采用版本不迁移。模型仍负责理解原文、适用规则、CRU方向及选择；程序保留真实回执/上下文检查、明确图冲突拦截、有限组分解析核对、来源绑定及类型关系检查。优选名认证仍为空，不能把模型自查称独立审查。

- 相对立构it-/st-/at-与原文引用和模型tacticity主题核对绑定；指定编码立体、盐、电荷及同位素检查不放宽。构成图相等不证明链级立构。参考[IUPAC立构定义](https://iupac.org/wp-content/uploads/2019/09/PAC-REC-19-04-09_MC190830.pdf)。
- 单体来源未知时，可采用有类别规则理由及产物限定的较宽类别名，不发明具体单体来迎合解析器。例如[IUPAC polycarbamate类别](https://goldbook.iupac.org/terms/view/15273)。结果明确为MODEL_CLASS_NAME_REVIEWED_WITH_TOOL_GAPS，不能称整图匹配或唯一产品结构。
- 新证据声明1.3允许使用已命名共聚侧链，要求骨架/侧链指向接枝产物的类型关系。一个共聚侧链是一个聚合物身份，不是若干有限单体；保留子身份假设。
- feasible_hypothesis表示相容可行但未证明最可能。most_likely_hypothesis额外要求真正备选、比较理由和来源；不能无依据升级。
- 已发现的冲突以多个原值、表示及出处保留；unresolved/hypothesis/source_confirmed分别记录。身份冲突未解决时用较宽名，按假设选择则保留假设。非命名数值冲突保留但不无谓拒绝名称。这些事实进入同一Kernel证据。程序不能保证模型发现所有未声明冲突。
- 原子保存仅对Windows暂时共享/拒绝错误增加最多五次替换尝试、约0.56秒等待；永久失败仍抛出，旧目标不被部分写入。它不保证多写者事务或解决全部Windows拒绝。
- 新任务的source_only低聚物所拥有的有限图是来源组分，不等于一个有限低聚物产品；不再无意义地把类别/来源高分子名送入有限OPSIN入口而导致回执失效。主要有限单体/组分及完整有限产品仍需有限图核对；类别路线不能用于单体来绕过验证。

本次是通用合同修订，不按论文ID加模板，不增加默认面板、名称答案表、人工参考求解或评分模块。保留完整全局上下文失效检查，没有为减少调用而削弱来源/身份保护。新实现需要自己的固定文献试运行观察；既有32/33交付统计不能替代它。
