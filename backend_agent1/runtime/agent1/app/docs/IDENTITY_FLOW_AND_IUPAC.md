# 化学身份证实际流程与 IUPAC 持续改进

任务：IDENTITY-FOUNDATION-INTEGRATION-20261001-01。化学运行时仍为 0.9.0；应用接线合同为 identity-foundation/1.1。本文件说明已实现的边界和后续推进方式，不启动新论文、旧队列或定时任务。

## 当前实际流程

1. 用户提交 PDF 或文本，宿主保存来源及其 SHA256。PDF 用 MinerU 解析，同时保存全文、页索引、原 PDF 和独立原页图；文本保留原输入。四篇首跑已经完成这一步，本次修订直接使用封存来源，不再次调用 MinerU。
2. 每篇由一个持续的 gpt-6.1-sol/xhigh 主会话理解正文和原图。它读取的只有本篇来源、当前候选和领域工具；用实际读图记录区分观察、解释、假设和未知。来源名称不自动变成聚合事实。每篇原总预算 60 分钟，最后 15 分钟停止新的组分或公共查询，完成修正和交付。
3. 主会话建立材料、成员、必要单体/投料/反应辅助组分及其角色；保存组成基准、构成、分子量/分布、立构、接枝含量、盐/电荷等身份信息。一般力学、DSC、流变数据不强求。共混关系与共价连接分别表达；混合比例不会自动转成 CRU 摩尔分数。
4. `check_structure` 接受明确范围的候选图，保留原子映射、立构、同位素、电荷、盐和开放端口。RDKit 检查并计算对应范围的式和性质。有限分子走有限图命名入口，重复图走重复构成入口；局部网络/接枝片段不能冒充完整材料图。
5. 可按实际需要调用 OPSIN、PubChem/CIR、已有规则命名和子单元组装工具。OPSIN 是有限名称到候选图的解析；公共数据库是限定有限组分的外部候选。二者都不能证明实物产品或聚合反应。每次实际调用及失败保存回执；公共查询有 12 次尝试上限和缓存，读页面不发网络请求。CAS 当前未配置。
6. `upsert` 保存唯一当前候选；修改保留撤回记录。`review` 将明确已供的重复构成、组分、关系、制备依据、来源事实、身份属性及未知送入同一 `Kernel/create_passport/NamingService`。必须显式声明 `constitution.graph_id + coverage: ideal_repeat` 才能把相应重复图作为完整理想重复构成；一般关联图仍作为限定范围证据。有限组分走独立有限图校验，不包装成聚合物。
7. 复核分别给出编码图一致、来源描述一致、不适用、规则不支持或冲突。有限图比较保留连接、立构、同位素和电荷，公式相同不足以通过。重复图仅比较工具支持的无向非手性周期构成；工具不支持立构时保留 UNKNOWN/UNSUPPORTED。确定的图名冲突阻止采用；规则不支持允许如实保留候选，不形成科学通过率。
8. 宿主检查当前状态 hash 和必需证据，保存不可变 bundle、采用指针并 hash 读回。输入/图/关系/工具绑定改变后必须重新复核。生成页、文献页和组分库统一读取同一采用版本。
9. 封存后的修订另建 revision，有父版本、理由、工具证据、实现 hash 和差异。预览与采用分开；页面可回放上一版本。首次任务、首跑指针、工具回执和原 bundle 不重写。本次开发修订是用户要求的本地再校验，主会话模型调用与 MinerU 调用均为 0，不冒充新的无人干预首跑。

## 流程是否合理

总体合理：阅读和范围判断需要主会话，结构计算和有限表示的一致性适合确定性工具；图、名字、实验材料及证据分别存储，版本与回执能定位问题。本次补上了原来“复核只看字符串和存在性、已收图没有成为显式构成输入、有限图误走重复图入口”的断点，也恢复了组分性质的正常阅读。

仍有实质限制：同一模型建图和选名会有共同错误；图名闭环只证明两种表示相容，不能证明原图读对。来源型名称到单体图不证明实际产物。RDKit 支持的图合法不等于实验身份准确。当前重复构成命名规则对取代硅、三嗪/多杂环、方向和优选位次覆盖不足；实物接枝键、EPDM 完整构成、网络拓扑等仍依赖来源证据。一个主会话加有限预算合理但不能保证每篇科学完成。独立化学审核保持 NOT_REVIEWED。

## 持续提升的具体路径

按两条线推进。表示一致性线已经接通，继续处理来源简称、候选组合、盐/电荷和工具失败。IUPAC 规则线需要新增可审查的一般规则，不能靠改提示词或查 PubChem 给高分子补一个貌似正式的名字。

1. **优先扩展当前真实缺口**：对 diaryl siloxane 的取代硅子单元、polyguanamine 的三嗪/phenylimino/alkylene 子单元做一般图识别和明确端口验证。规则依据绑定到官方章节、适用图类和版本；不要把论文编号/人工答案写进规则。记录未支持图的原因，先解决识别/分解，再做优选。
2. **补优选构成与方向规则**：实现候选 CRU 分解、优先级、方向、位次和括号的受限规则；每步给 trace、可拒绝条件和范围。周期图相等只覆盖构成等价，不能替代这些规则。`declared_cru` 是当前接入点，现阶段仅做已供子单元的一致性核对。
3. **完善不规则材料表达**：接枝、共聚、共混和网络分别按来源支持的关系命名；未知连接、序列、位点和拓扑仍显示未知。仅 PP 主链片段和 DMI 内部残基无法构成完整 PP-g-DMI IUPAC 结构型名称。
4. **每次规则升级的交付门槛**：新合同/冻结知识快照；原合同可回放；新增独立来源例和同分异构、方向、取代、立构、同位素、盐/电荷等负例；实际工具日志与输入 hash；逐图类列新增支持和拒绝；列撤回、未知及失败例。由独立化学审查确认规则后才升级相应声明，不能把自己生成的 expected 标为独立审查。
5. **评价口径**：分别记录字段保留、图/名称一致性、规则支持、优选选择、来源/实物证据和独立审查，避免一个总准确率。人工 JSON 和旧版本用于封存后的逐项人工复核，发生冲突回到原文；本应用不添加打分/对照模块，也不把这些资料作为求解输入。本次已完成的人工/旧版本审查见原项目同任务报告；其中参考本身存在 3g 的 methyl/phenyl 冲突，不能直接当 gold。

下一次可独立交付的化学任务是“取代硅与三嗪子单元识别及有来源的受限命名规则包”，其通过标准是新增一般规则、反例和独立审查证据，不是四篇名字都非空。需要持续改进但不自动启动新论文或历史队列。

依据：[IUPAC 高分子命名简明指南](https://iupac.org/wp-content/uploads/2019/07/140-Brief-Guide-to-Polymer-Nomenclature-Web-Final-d.pdf)、[Purple Book](https://iupac.org/what-we-do/books/purplebook/)、[OPSIN 官方说明](https://github.com/dan2097/opsin)、[PubChem PUG REST](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest)。指南区分来源型和结构型命名；结构型命名需处理优选 CRU、子单元排序与编号。数据库的有限分子名字不能补足实验材料的构成证据。
