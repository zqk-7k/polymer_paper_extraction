# Unresolved identity or naming

gap_kind accepts missing_evidence, ambiguous, conflicting or unsupported;
an omitted kind defaults to unsupported. Ambiguity means competing readings,
not source absence. Keep conflicting claims with their evidence bindings;
do not collapse disagreement into a definitive name.

Only an explicit evidence_status of not_read with an available reference
justifies an evidence-reading suggestion: read_image for image_src, otherwise
read_source for source_refs. If both exist, image takes precedence. The host
retains the other references and chooses actual tool arguments and budgets.
This is advice, never tool execution or a declaration of source truth.

Otherwise retain_partial_identity. Unsupported operations preserve the partial
identity and name with their limits. Do not repeat a model call or resubmit an
unchanged graph to escape an unsupported result. Preserve unknowns, explicit
roles, salt/stereo detail, assumptions and known references. Do not attempt
exact-name verification, add a reviewer, merge samples or update records
automatically. New unread evidence may be read without claiming the unsupported
operation has become supported.
