# 经开发集审核后冻结的性质召回记忆

该记忆只提供可复用的漏抽检查模式，不包含冻结测试论文的 PoLyInfo 数值、答案或
样品映射。所有新增记录仍须由当前论文原文证据支持。

1. 在提交结果前建立覆盖清单，依次检查正文、表格、表题、图注和补充说明中的
   定量性质。不得因为正文只讨论代表值而省略表格中的其他样品行。
2. 对热性质同时检查 Tg、Tm、结晶温度、热分解温度以及与分解温度配套报告的
   失重百分比或判据。不同方法、不同循环或不同样品状态的值必须分开记录。
3. 对分子量表格同时检查 Mn、Mw、Mv、Mz 和分散性。多行样品优先输出完整
   PropertySeries；样品只能定位到 PolymerEntity 时输出 unresolved Series，不能
   因无法确定 sample_id 而静默丢弃。
4. 对 DMA/力学结果分别检查储能模量、损耗模量、损耗因子、拉伸强度、模量和
   断裂伸长率。一个图或一张表包含多个性质时，每个性质分别建立记录。
5. 对界面与电学结果检查接触角、介电常数、介电损耗、电导率和体积电阻率。
   只有原文明确给出数值时才抽取，不从曲线像素估读。
6. 表格属性列有两个及以上有效数据行时，不得只抽第一行或正文举例行。若行标签
   无法绑定具体样品，保留为 unresolved，而不是猜测或删除。
7. 每个新增值必须保存能定位的 block_id、页码和 bbox。性质名、数值、单位及
   条件必须逐字来自对应证据，不得根据 PoLyInfo、常识或其他论文补齐。
