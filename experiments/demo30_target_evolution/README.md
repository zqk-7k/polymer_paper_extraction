# demo30 × PoLyInfo 全量审计与目标驱动自进化

## 1. 目标

本实验包含两个互不替代的评价口径：

1. 对 demo30 的 32 篇候选结果与本地 PoLyInfo 记录进行全量对照，定位性质、条件、工艺和专用字段缺口。
2. 在不把 PoLyInfo 答案写入提示词的前提下，引入九类性质归属 Agent 和受控自进化，使独立冻结集的九类文献级 Recall 达到 80% 以上，同时守住准确性、证据和主体绑定门禁。

PoLyInfo 在本实验中是 reference-aligned anchor，不是完整全文 gold。“仅 PoLyInfo”和“仅抽取”都必须回原文裁决，不能直接解释为漏抽或错误。

## 2. demo30 全量基线

## 3. 九类性质归属 Agent

Agent 位于 `extraction/agents/specialized_coverage.py`，只处理九类高风险专用字段，不替代主 workflow。

```text
Stage 0 原文与表格
        +
Stage 2 聚合物实体
        +
Stage 3 样品目录
        +
现有 published / unresolved 候选
        ↓
受控检索与九类逐项核验
        ↓
LLM 只判断语义和主体归属
        ↓
确定性验证：原文逐字短语、block/bbox、样品和实体外键、字段类型
        ↓
candidate_only 候选 → 专家审核
```

Agent 的输出不能自动入库。数值型字段必须含数值；证据必须来自输入 block；样品和聚合物必须引用现有 ID。模型改写原文、引用未知证据或给出非法外键时，单条候选会被降级为 `ambiguous`。

## 4. 受控自进化

自进化不修改模型权重，不读取冻结集的 PoLyInfo 答案。它只允许两类可审计变化：

1. 专家批准的无数值检索别名，例如 `molar mass`、`eta inh` 和 `phase separation`。
2. 从校准错误归纳出的通用规则，例如表格必须读取 `table_cells`，数值型字段必须出现数值，标题、摘要、结论和表格应进入全局语境复核。

两轮校准均不计入最终成绩：

| 轮次 | 发现 | 受控修改 |
|---|---|---|
| calibration v1 | 表格字段漏检；定性“high molecular weight”误归为平均分子量 | 修复 `table_cells/table_body` 检索；增加数值型发布门禁 |
| calibration v2 | 基于关键词的检索看不到未命中字段的全局语境 | 增加标题、摘要、结论和表格的全局语境复核 |

## 5. 最终冻结验证

最终 5 篇由 `SHA-256(reference_no)` 排序确定，排除开发集、两轮校准集和此前已人工检查的论文。PoLyInfo 只在 Agent 输出完成后用于评分。

冻结论文：

- `reference_no_0041326`
- `reference_no_0027435`
- `reference_no_0042480`
- `reference_no_0033940`
- `reference_no_0024941`

| 系统 | 九类文献级 Recall | 锚点 Precision |
|---|---:|---:|
| 当前 workflow | 40.00% | 100.00% |
| 基础归属 Agent | 80.00% | 85.71% |
| 自进化版本 | **86.67%** | **86.67%** |

自进化版本同时达到：

- 证据验证率 100%；
- 主体解析率 100%；
- Recall 相对 workflow 提升 46.67 个百分点；
- 所有预注册门禁通过，可进入专家审核；
- 自动生产发布仍保持关闭。

## 6. 结果边界

86.67% 是 5 篇独立冻结论文上“九类 source field 是否在文献级被覆盖”的 Recall。它不能替代 demo30 全量 1,550 条数值记录的 12.97% 精确 Recall，也不能证明全部抽取结果达到 PoLyInfo 质量。

当前结果证明的是：专业归属 Agent 和受控自进化能够显著恢复高风险专用字段，同时保持证据与主体关系有效。下一阶段应把相同闭环扩展到热分解、分子量、Tg/Tm、电学性质、测量条件和样品形态，并在更大的人工全文 gold 上验证。
